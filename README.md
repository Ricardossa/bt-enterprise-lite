# BT Queue Enterprise (Unidade)

## Visão Geral
O **BT Queue Enterprise** é o software de operação local para filas de atendimento. Ele gerencia o ciclo completo do cliente na unidade, desde a emissão da senha até o atendimento final.

## Principais Recursos
- **Totem Híbrido**: Emissão de senha digital (QR Code) ou física (Impressora).
- **Painel de TV**: Chamada sonora com voz nativa e histórico.
- **Acompanhamento Mobile**: O cliente acompanha a fila no próprio celular.
- **Operação Offline**: Funciona sem internet, sincronizando com a Master assim que a conexão retorna.

## Configuração Local
- Banco de Dados: MariaDB SaaS.
- Subdomínio Oficial: `lite.brandaotech.com.br` (Porta 80).
- Servidor Web Local: Porta 8120.
- Ponte de Impressão: Porta 8002.
